## 🏷️ Release Notes

### Version 1.0.0 (2026-09-10)

**Initial Release**

This is the first public release of Competitor Researcher. It includes:

- React 18 frontend with TypeScript
- Vite for fast development and production builds
- Express backend server
- Google Gemini API integration for AI-powered research
- Complete competitor tracking system
- Report generation functionality
- Real-time alerts

**Features**:
- Add and track unlimited competitors
- AI-powered competitive analysis
- Market trend analysis
- Historical data tracking
- Actionable intelligence reports
- Real-time change alerts
- Responsive design
- Production-ready builds

**Usage**:
1. Install dependencies: `npm install`
2. Configure .env: `cp .env.example .env`
3. Add your API key
4. Start development: `npm run dev`
5. Build for production: `npm run build`
